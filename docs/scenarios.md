# Сценарии «Рядом»

Документ фиксирует структуру быстрого сценария MVP проекта «Рядом».

Это единый источник истины для:
- категорий;
- подкатегорий;
- мест;
- правил выбора сценария;
- поведения AI fallback.

---

## 1. Категории

### 1. `tantrum` — Истерика / сильный плач

Подкатегории:

| Код | Название |
|---|---|
| `forbidden` | Запретили что-то |
| `toy_taken` | Забрали игрушку |
| `denied_request` | Отказали в просьбе |
| `leave` | Нужно уходить |
| `dressing` | Нужно одеваться |
| `unknown` | Причина непонятна |

---

### 2. `refusal` — Не хочет что-то делать

Подкатегории:

| Код | Название |
|---|---|
| `sleep` | Не хочет спать |
| `eat` | Не хочет есть |
| `dress` | Не хочет одеваться |
| `brush_teeth` | Не хочет чистить зубы |
| `clean_up` | Не хочет убирать |
| `leave` | Не хочет уходить |
| `bath` | Не хочет купаться |

---

### 3. `anger` — Злится / психует

Подкатегории:

| Код | Название |
|---|---|
| `irritated` | Раздражён |
| `crying` | Плачет от злости |
| `shouting` | Кричит |
| `arguing` | Спорит |
| `throws_things` | Бросает вещи |
| `wants_to_hit` | Хочет ударить |
| `unknown` | Причина непонятна |

---

### 4. `aggression` — Бьёт / кусается

Подкатегории:

| Код | Название |
|---|---|
| `hits_adult` | Бьёт взрослого |
| `hits_child` | Бьёт другого ребёнка |
| `bites` | Кусается |
| `kicks` | Пинается |
| `pushes` | Толкается |
| `throws_things` | Бросает вещи |
| `other` | Другое |

---

### 5. `not_listening` — Не слушается / всё делает наоборот

Подкатегории:

| Код | Название |
|---|---|
| `ignores_request` | Игнорирует просьбу |
| `says_no` | Отвечает «нет» |
| `does_opposite` | Делает наоборот |
| `argues` | Спорит |
| `runs_away` | Убегает |
| `transition` | Не хочет переключаться на другое действие |

---

### 6. `other` — Другая ситуация

Подкатегории отсутствуют.

Пользователь описывает ситуацию свободным текстом.

Такая ситуация передаётся непосредственно в AI.

# 2. Места

Место является отдельным параметром и не является подкатегорией.

| Код | Название |
|---|---|
| `home` | Дома |
| `shop` | В магазине |
| `street` | На улице |
| `playground` | На площадке |
| `car` | В машине |
| `guest` | В гостях |
| `other` | Другое |

---

# 3. Логика выбора сценария

Для категорий с готовыми сценариями система сначала ищет подходящий сценарий в базе данных.

Учитываются:

- `category`;
- `subcategory`;
- возраст ребёнка;
- `place`.

При поиске места используется следующий порядок:

1. Сначала ищется сценарий с точным совпадением `place`.
2. Если такой сценарий не найден — ищется универсальный сценарий, где `place = NULL`.
3. Если подходящего сценария в базе нет — запрос передаётся в AI.

---

# 4. AI fallback

AI используется, если подходящего готового сценария в базе данных нет.

Особый случай:

`category = other`

В этом случае готовый сценарий не используется, ситуация передаётся непосредственно в AI.

---

# 5. Первоначальный набор готовых сценариев MVP

Для первой версии создаём 10 качественных готовых сценариев:

1. `tantrum / denied_request`
2. `tantrum / leave`
3. `refusal / sleep`
4. `refusal / dress`
5. `anger / shouting`
6. `anger / throws_things`
7. `aggression / hits_adult`
8. `aggression / bites`
9. `not_listening / ignores_request`
10. `not_listening / transition`

Категория `other` в первоначальный набор готовых сценариев не входит.

---

# 6. Архитектура сценариев

Общий поток:

User
→ Category
→ Subcategory
→ Place
→ Scenario Repository
→ готовый сценарий из БД

Если сценарий не найден:

User
→ Category
→ Subcategory
→ Place
→ AI Service
→ AI Recommendation

---

# 7. Связь с базой данных

Готовые сценарии хранятся в таблице:

`scenarios`

Основные поля:

- `category`
- `subcategory`
- `age_min`
- `age_max`
- `place`
- `title`
- `steps`
- `phrase`
- `avoid`
- `if_not_helped`
- `is_active`

Python-файл `app/db/seed_scenarios.py` используется для первоначального заполнения базы данных.

Документ `docs/scenarios.md` описывает продуктовую структуру, а база данных содержит конкретные тексты готовых сценариев.
